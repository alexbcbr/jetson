## Project Overview

This is a Jetson project with a utility API service (`util/api/`) — a FastAPI app backed by SQLite, containerized with Docker. It serves customer data seeded with Faker.

## Commands

All commands run from `util/api/`:

```bash
# Build & run (Docker)
make build          # build Docker image
make run            # build + run container on port 8000
make stop           # stop + remove container

# Database
make seed           # seed SQLite DB with 10 fake customers (runs db-init/seed.py via uv)

# Tests
make unit-test      # run pytest suite: uv run pytest tests/ -v
make test           # smoke test: curl localhost:8000/customers

# Dev server (no Docker)
uv run uvicorn main:app --host 0.0.0.0 --port 8000
```

## Architecture

- **`main.py`** — FastAPI app with two endpoints: `GET /` (health) and `GET /customers` (list all customers).
- **`db.py`** — SQLite access layer. Reads from `data/customers.db`. The `data/` directory is created at seed time.
- **`db-init/`** — Database setup scripts. `init_db.py` creates the schema; `seed.py` calls `init_db()` then inserts 10 Faker-generated rows.
- **`Dockerfile`** — Builds the image using `uv` for dependency management. Seeds the database during image build.
- **`tests/`** — pytest tests. `test_db.py` monkeypatches `DB_PATH` to use a temp SQLite file.

## Key Details

- Package manager: **uv** (not pip). Use `uv run` to execute Python scripts/tools.
- Python >=3.11 required.
- The SQLite DB file (`data/customers.db`) is not checked in — it's generated by `make seed` or during Docker build.
